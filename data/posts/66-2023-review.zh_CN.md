## React Server Components

### RSC 的核心价值

React Server Components（RSC）彻底改变了 React 的渲染模型：

```tsx
// 服务端组件 —— 在服务端渲染，不发送到客户端
async function UserProfile({ userId }) {
  // 直接访问数据库，无需 API 层
  const user = await db.users.findUnique({ where: { id: userId } });

  return (
    <div>
      <h1>{user.name}</h1>
      <p>{user.email}</p>
    </div>
  );
}

// 客户端组件 —— 在客户端渲染，支持交互
'use client';

function LikeButton({ postId }) {
  const [liked, setLiked] = useState(false);

  return (
    <button onClick={() => setLiked(!liked)}>
      {liked ? '❤️' : '🤍'}
    </button>
  );
}
```

### 性能提升

```
传统 SPA：
  JS Bundle: 200KB
  首屏时间: 3-5 秒（等待 JS 加载和执行）

RSC 模式：
  JS Bundle: 80KB（只包含客户端组件）
  首屏时间: 0.5-1 秒（服务端渲染 + 流式传输）
```

### 实际案例

```tsx
// Next.js App Router 中的 RSC
// app/dashboard/page.tsx

// 服务端组件
async function DashboardPage() {
  // 并行获取数据
  const [user, stats, recentActivity] = await Promise.all([
    getUser(),
    getStats(),
    getRecentActivity(),
  ]);

  return (
    <div className="dashboard">
      <h1>欢迎, {user.name}</h1>

      <Suspense fallback={<ActivitySkeleton />}>
        <RecentActivityList activities={recentActivity} />
      </Suspense>
    </div>
  );
}
```

## Server Actions

### 表单处理的革新

Server Actions 让表单处理变得极其简单：

```tsx
// 传统方式：需要单独的 API 路由
// app/api/contact/route.ts
export async function POST(request) {
  const data = await request.json();
  await sendEmail(data);
  return Response.json({ success: true });
}

// 客户端组件
'use client';
function ContactForm() {
  const [loading, setLoading] = useState(false);
  const handleSubmit = async (e) => {
    e.preventDefault();
    setLoading(true);
    await fetch('/api/contact', { method: 'POST', body: ... });
    setLoading(false);
  };
}

// Server Actions 方式
async function submitContact(formData: FormData) {
  'use server';
  const name = formData.get('name');
  const email = formData.get('email');
  await sendEmail({ name, email });
}

// 直接在组件中使用
function ContactForm() {
  return (
    <form action={submitContact}>
      <input name="name" />
      <input name="email" />
      <button type="submit">提交</button>
    </form>
  );
}
```

## 新兴工具与框架

### Bun 运行时

Bun 作为 Node.js 的替代品，引起了广泛关注：

```bash
# Bun 的优势
bun install      # 比 npm/yarn 快 10-100 倍
bun run dev      # 内置开发服务器
bun test         # 内置测试运行器
bun build        # 内置打包器
```

```javascript
// Bun 原生支持 TypeScript
// 无需额外配置，直接运行

// Bun 的 HTTP 服务器

  fetch(req) {
```
